## 共通して大切にしていること

- **人が確認する工程を残す**：AIの出力や不備のあるデータは自動で進めず、確認待ちに分ける
- **失敗しても困らない**：再試行、二重処理の防止、処理ログで原因を追える
- **引き継げる**：日本語コメント付きのコード、設定はシートやプロパティで変更、導入手順書つき
- **テストで確かめてから渡す**：外部サービスを差し替えたテストで、異常系まで確認
